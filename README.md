# Veloura

Veloura is a movie discovery site: [veloura-movies.rosenberg-cinema.workers.dev](https://veloura-movies.rosenberg-cinema.workers.dev/).

Browse trending, popular, acclaimed, and now-playing films. Search by movie, person, or studio. Open a film for the full record — story, cast, crew, production companies, release dates, where to watch, videos, and artwork.

Movie data and images come from [TMDB](https://www.themoviedb.org/). This product uses the TMDB API but is not endorsed or certified by TMDB.
